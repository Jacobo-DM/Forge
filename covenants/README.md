# Covenants

This chamber holds the binding orientation documents of the Forge.

Covenants are not ordinary notes, declarations, or project pages. They name the conditions under which the work may continue with integrity.

They are meant to be returned to when the work grows too quickly, becomes too polished, or begins to forget what it is for.

## Current Covenants

- [Covenant of the Flower Road](flower-road-covenant.html)
- [Living Systems AI Covenant](../living-systems-ai-covenant.html)

## Relationship to Declarations

Declarations name a stance.

Covenants name a binding orientation.

A declaration may say: this is where we stand.  
A covenant asks: can the work still be carried this way?

## Stewardship

Do not multiply covenants quickly.

A covenant should be added only when it is strong enough to guide more than one project, page, offering, or tool.

If a text belongs to one project only, place it with that project.

If it orients the whole Forge, place it here.
